# Как устроено

## Состав расширения

| Объект | Назначение |
|---|---|
| `ast_ПеренестиОбъект` | Общая команда `Alt+P`: определяет выбранные данные и открывает окно; в открытом окне выполняет перенос |
| `WS_КонтекстФормыКлиент` | Определяет выбор без привязки к именам форм: выделенные строки, `Объект.Ссылка`, `Параметры.Ключ` |
| `WS_НастройкаОбмена` | Окно переноса со списком и справкой |
| `WS_НастройкиПереноса` | Форма «Настройки»: приём, адрес рабочей базы, пароль служебного входа |
| `WS_ТранспортСервер` | Сторона источника: собирает пакет, подписывает и отправляет запросы |
| `WS_ПриёмникСервер` | Сторона приёмника: проверяет запрос, сравнивает данные и записывает пакет |
| `WS_СериализацияСервер` | Сериализация объектов и наборов записей, подпись, ключи строк |
| `WS_ОкружениеСервер` | Идентичность и тип базы, служебный вход, хранение настроек |
| `ast_WSObmen` | Веб-сервис: `ast_Handshake`, `ast_Check`, `ast_Apply` |
| `WS_ОсновнаяРоль` | Права на объекты расширения |

## Протокол

1. **`ast_Handshake`** возвращает идентификатор базы, её тип (рабочая или копия), имя и версию конфигурации, версию протокола и расширения, время сервера.
2. **`ast_Check`** получает пакет и для каждого элемента отвечает, будет ли он создан, обновлён или останется без изменений, и что именно изменится. Также сообщает ссылки, которых на приёмнике нет. Источник добавляет эти объекты следующим уровнем и повторяет проверку, пока новых не останется.
3. **`ast_Apply`** повторно проверяет пакет и записывает отмеченные элементы одной транзакцией.

Версия протокола сейчас `3`. При расхождении версий запрос отклоняется.

## Подпись и доступ

Запрос содержит пользователя, базу-приёмник, время сервера приёмника и подпись:

```text
SHA256(СохраняемоеЗначениеПароля | операция | пользователь | приёмник | время | SHA256(тело))
```

Приёмник находит пользователя с тем же именем, считает подпись по своему хешу пароля и проверяет, что у пользователя есть полные права. Запрос старше 10 минут или адресованный другой базе отклоняется. Копия из бэкапа содержит тот же хеш, поэтому пароль не нужно ни вводить, ни хранить.

## Служебный вход

Платформа не пустит HTTP-запрос к веб-сервису без пользователя базы. Для этого в базе-приёмнике создаётся пользователь `WS_HotKeyTransfer` с ролью расширения. При включении приёма ему назначается случайный пароль. Пароль хранится в `ХранилищеОбщихНастроек` и попадает в бэкап, поэтому рабочая база и её копии знают один и тот же пароль, и перенос работает в обе стороны. Права на запись этот вход не даёт, разрешение даёт только подпись.

В конфигурациях на БСП служебный пользователь должен быть в справочнике «Пользователи», иначе сеанс не откроется. Форма «Настройки» это проверяет и исправляет по кнопке «Разрешить приём в эту базу».

## Где что хранится

| Что | Где | Попадает в бэкап |
|---|---|---|
| Пароль служебного входа | `ХранилищеОбщихНастроек`, ключ `ПарольВхода` | да |
| Адрес рабочей базы | `ХранилищеОбщихНастроек`, ключ `АдресРабочейБазы` | да |
| Использованные адреса | `ХранилищеОбщихНастроек` пользователя, ключ привязан к идентификатору базы | да, но копия их не видит |
| Идентичность базы | строка соединения: сервер и имя базы | нет, поэтому копия отличает себя от рабочей |

Константы и другие объекты метаданных не используются, поэтому расширение ставится без изменения структуры базы.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Как приёмник узнаёт пользователя | Подпись хешем пароля плюс полные права в обеих базах | У копии из бэкапа тот же хеш, пароль не вводится и не хранится |
| Что записывается | Только отмеченное | Контроль важнее автоматики |
| Связанные объекты | Только отсутствующие на приёмнике, до 10 уровней и 200 элементов | Список остаётся коротким, существующие объекты не перезаписываются |
| Изменения | Сравнение с приёмником: поля, табличные части, движения | Видно, что затрётся, лишнее не пишется |
| Атомарность | Весь пакет в одной транзакции | Простая гарантия от частичной записи |
| Повтор | Отдельного механизма нет | Запись по UUID и ключу записи не создаёт дублей |
| Журнал | Журнал регистрации приёмника | Свои таблицы не нужны |
| Какая база рабочая | Всё, где в имени нет отдельного признака копии | Ошибка приводит лишь к лишнему подтверждению |
| Режим записи | `ОбменДанными.Загрузка = Истина`, привилегированно | Перенос должен воспроизводить объект, а не заново выполнять бизнес-логику |

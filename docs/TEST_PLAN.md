# Проверки

Только на тестовых базах. Тест создаёт элементы справочника с префиксом `HKT_`, а на приёмнике очищает и восстанавливает движения одного документа и одну запись регистра.

## Автоматические

Статические проверки исходников: `cfe-validate`, `form-validate`. Проверка модулей платформой: `db-cfe-admin check`. Интеграционный тест (PowerShell 7, зарегистрированный `V83.COMConnector`, пароль в отдельном файле вне репозитория):

```powershell
tests/integration/run-transfer-smoke.ps1 -Server <сервер> -SourceRef <копия> -TargetRef <приёмник> `
  -TargetUrl http://<сервер>/<приёмник> -User <пользователь> -PasswordFile <файл>
```

Сценарии теста:

| Сценарий | Ожидание |
|---|---|
| Включение приёма | Служебный пользователь создан, сеанс веб-сервиса открывается |
| Нет служебного элемента в справочнике «Пользователи» | Состояние обнаружено, «Разрешить приём» создаёт элемент |
| Список «Куда» | Успешная проверка добавляет адрес в конец, неудачная не добавляет, перенос ставит адрес первым |
| Имена баз | `base_dev`, `copy_base`, `dev01` — копии; `devices`, `kopeyka`, `contest_base` — нет |
| Нет связанного объекта | Проверка показывает его со связью, на приёмнике ничего не появилось |
| Открытие из строки | По ключу строки находится объект или запись регистра; для отсутствующего объекта — пусто |
| Пароль служебного входа | Случайный, меняется; база со старым паролем не проходит вход, с новым проходит; повторное сохранение того же пароля не падает |
| Версия | Заполнена и совпадает на обеих базах |
| Адрес рабочей базы | Рабочая база принимает только свой адрес, копия только адрес рабочей; копия не сохраняет адрес другой копии; сохранённый адрес есть в списке «Куда» |
| Галочка снята | Записан только отмеченный объект |
| Галочка стоит | Записан и связанный объект |
| Объект совпадает | Действие `unchanged`, связанных строк нет |
| Объект изменён | Действие `update`, названо изменённое поле |
| Проведённый документ | Изменения в движениях названы, движения восстановлены, документ остался проведённым |
| Повтор после переноса | Действие `unchanged`, ложных отличий нет |
| Журнал приёмника | Есть запись с пользователем и составом |
| Версии объектов | С флажком у существующего и нового объекта появляется версия с автором-пользователем и причиной; без флажка версии нет |
| Запись регистра сведений | Запись восстановлена по ключу |
| Адрес этой же базы | `WS_SAME_ENVIRONMENT` |
| Поддельная подпись | `WS_ACCESS_DENIED` |
| Неизвестный пользователь | `WS_ACCESS_DENIED` |
| Устаревший запрос | `WS_REQUEST_EXPIRED` |
| Запрос для другой базы | `WS_TARGET_MISMATCH` |
| Служебный вход | Внешнее соединение под ним запрещено |

## Ручные

| Сценарий | Ожидание |
|---|---|
| `Alt+P` в карточке документа и справочника | Окно показывает этот объект |
| Снять галочку со связанного объекта | Зависимые строки исчезают, итог пересчитан, строка называет битую ссылку; повторно поставить — всё возвращается |
| Двойной щелчок по строке, кнопка «Открыть объект» | Открывается объект этой базы или запись регистра; щелчок по галочке объект не открывает; для битой ссылки — сообщение в окне |
| `Ctrl+Enter`, повторный `Alt+P`, `F5` в окне | Перенос или проверка без мыши; галочки при `F5` сохраняются |
| Перенос из базы без признака копии | Красное предупреждение |
| `F1` или кнопка «Справка» в окне | Открывается инструкция |
| Несколько выделенных строк в списке | Перенесены все выделенные и только они |
| Группировка в списке, строка табличной части | Не попадают в перенос |
| `Alt+P` в форме без данных | Понятное предупреждение |
| Изменённая незаписанная карточка | Предупреждение: будет перенесена записанная версия |
| Строка регистра с полем-ссылкой | Можно выбрать запись или объект из поля |
| Кнопка «Настройки» | Видна только с полными правами; приём включается; адрес сохраняется; после закрытия пустое поле «Куда» заполняется |
| «Показать пароль», ввод пароля, «Новый пароль» | Пароль виден только по команде; ввод применяется и к служебному пользователю; смена спрашивает подтверждение |
| Копия, восстановленная из бэкапа рабочей базы | Расширение на месте, безопасный режим выключен, поле «Куда» заполнено |
| Цель без признака копии в имени | Красная надпись, причина и подтверждение обязательны |
| Пользователь без полных прав | Понятный отказ, ничего не записано |
| База с запретом модальности | Окно работает |
